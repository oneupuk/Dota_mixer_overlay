# README images

[Remotion](https://www.remotion.dev) stills for the main README, built from real in-game captures
(Demo Hero, 2560×1440) in `public/`.

| Composition | Output |
|---|---|
| `Hero` | `docs/hero.jpg` |
| `HowToUse` | `docs/how-to-use.png` |

```console
npm i
npm run render   # writes both into docs/
npm run dev      # Remotion Studio, to tweak layouts
```
